# Cima Becco

Atlante collaborativo delle montagne italiane: cime, itinerari, pianificazione e navigazione GPX.

Questo repository nasce come progetto indipendente, basato sul software open source [HillGPX](https://github.com/StarlightsJourney/HillGPX), distribuito con licenza MIT. Gli avvisi di licenza e attribuzione originali sono mantenuti.

> Stato: inizializzazione tecnica. Le funzioni di routing, import dei dati CAI/SAT e navigazione non sono ancora da considerarsi operative finché non saranno integrate e testate.
